# O-SCD++

**Code coming soon.**

O-SCD++ is the next step in the [O-SCD line](../README.md) of online scene change detection. Like [O-SCD](../O-SCD), it will live in this directory as a self-contained codebase with its own environment, dependencies and scripts.

- Project page: <https://chumsy0725.github.io/O-SCD/plusplus/>
- Dataset: [PASLCD on HuggingFace](https://huggingface.co/datasets/ChamudithaJay/PASLCD)

The code will be released for non-commercial academic research and evaluation only. Third-party components will retain their own licenses.
